# Green Monkey logo

`green-monkey-logo-v1.png` is the original generated transparent PNG lockup: a
forest-green monkey mark and lowercase wordmark. Created with the built-in image
generation tool. This is a raster asset, not editable vector artwork. The shared `BrandLogo` component uses this asset in marketing, POS login/header
and public ordering. Compact POS headers show the symbol using a CSS viewport.

## Generation prompt

Use case: logo-brand. Create a single finished premium logo for Green Monkey, a modern restaurant POS software brand. Clean horizontal lockup on a genuinely transparent background. On the left a distinctive compact geometric monkey head symbol in solid deep forest green (#164D35): rounded ears, confident friendly face, clever negative-space facial features and a subtle curved smile, memorable silhouette, minimal bold shapes readable at app-icon size. Cool, sophisticated and approachable, not a childish cartoon. On the right the exact lowercase wordmark "green monkey" in beautifully balanced bold modern rounded grotesk lettering, same deep forest green. Strong designer-crafted typography with subtle custom character, excellent kerning. Symbol slightly taller than wordmark. Generous clean margins around the complete lockup, artwork fills most width, centered. Flat vector-like design with razor-sharp edges. One logo only. No mockup, no additional text, no slogan, no grid, no shadows, no gradients, no texture, no 3D, no watermark, no decorative scenery. Transparent background, not a checkerboard drawing.
